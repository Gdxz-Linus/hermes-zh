# 视频字幕提取与内容结构化提炼指南（YouTube Content）

## 概述

指导从视频链接中快速提取原始字幕文本，并将其清洗、提炼并重构为高质量的结构化文本资料。支持将长篇口语演讲、技术访谈或操作教程转化为带有时间戳的分段章节纪要、核心论点摘要以及完整的分析报告。

## 适用场景

- “帮我提取这个技术分享视频的字幕，并总结出讲者表达的核心观点”
- “视频内容太长，整理成一份带有时间戳重点的逐章节文字记录”
- “将一段访谈视频的内容提炼为一篇逻辑清晰的技术博文或要点速览”

---

## 一、 辅助脚本调用与核心参数

提取功能由内置的 Python 脚本提供（位于本技能目录下的 `scripts/fetch_transcript.py`）。脚本支持标准的视频长链接、短链接、短视频以及纯视频编号（11 位字符串）：

```bash
# 辅助脚本路径简写
YT_SCRIPT="scripts/fetch_transcript.py"
```

### 常用提取命令范式：
1. **提取纯文本正文（便于直接交由大模型进行深度阅读与总结）**：
   ```bash
   python scripts/fetch_transcript.py "<视频链接或ID>" --text-only
   ```
2. **提取带有时间戳的结构化字幕（便于精确定位视频关键节点）**：
   ```bash
   python scripts/fetch_transcript.py "<视频链接或ID>" --timestamps
   ```
3. **指定语言与降级回退链（优先提取中文，缺失时回退到英文）**：
   ```bash
   python scripts/fetch_transcript.py "<视频链接或ID>" --language zh,en
   ```
4. **输出完整元数据 JSON（包含视频标题、作者、发布时间与分段数据）**：
   ```bash
   python scripts/fetch_transcript.py "<视频链接或ID>"
   ```

## 二、 内容处理与结构化提炼标准

获取到原始字幕文本后，由于口语表达普遍存在口头禅、重复语病和跳跃式表达，必须按以下三步进行重构提炼：

### 第一步：口语废话清洗与段落合并
- 剔除语气助词、重复结巴语句与口头垫字；
- 将破碎零散的单句字幕按照完整语义聚合成连贯的书面语段落。

### 第二步：分章节时间戳标注
梳理视频逻辑主线，划分清晰的主题章节，每个章节必须标明起始时间节点：
```markdown
### 00:00 - 04:30 | 背景引入：为什么传统架构难以应对突发流量
陈述讲者指出的历史难题，概括当时系统遭遇的性能瓶颈。

### 04:31 - 12:15 | 核心设计：基于多路复用的异步连接池重构
详细拆解讲者展示的核心技术方案，列出关键实现原则。
```

### 第三步：提炼核心论点与关键结论
在文末必须出具独立的核心要点矩阵：
- **主要技术洞察**：讲者提出的 3 至 5 个核心技术主张或经验教训；
- **具体实施建议**：可直接执行的操作要点；
- **遗留未决争议**：讲者在视频中提出但未给出定论的开放性问题。

## 三、 常见问题与排查指南

1. **视频未提供可用字幕报错**：
   - 若视频上传者未开启自动生成字幕功能且未上传外挂字幕文件，脚本将无法提取文本；
   - 此时需明确告知用户该视频未包含字幕音轨，建议使用外部音频转录工具处理。
2. **网络连接受限**：
   - 提取视频元数据依赖正常的国际网络连接；在 Windows 终端中运行前，核对环境变量 `HTTP_PROXY` 与 `HTTPS_PROXY` 是否已配置。
