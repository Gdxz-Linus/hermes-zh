# 竞品动态追踪与市场情报监控指南（Competitor News Monitor）

## 概述

指导对指定企业、竞对产品或行业重点技术动态开展自动化跟踪，并生成附带一手证据来源的高质量情报简报。该流程并非泛化的网页字符比对，而是基于明确的业务事件分类标准、来源可信度层级、事件去重逻辑以及商业实质性影响评估展开。初始监控范围在前台确立，周期的增量抓取则交由后台定时任务（`cronjob`）调度执行。

## 适用场景

- “每周定期汇总这三家竞对公司的重大版本更新、产品发布与商业动作”
- “监控某家公司是否调整了产品定价或推出了新的计费套餐”
- “跟踪行业内相关的融资事件、战略合作、高管人事变动与安全突发事件”
- 配合后台定时任务定期输出结构化的技术与行业情报周报

---

## 一、 初始化配置流程（前台一次性执行）

严禁在未确立边界的情况下盲目开启定时抓取，必须按以下步骤执行：

### 第一步：明确监控标的与过滤规则
明确以下要素，确立内容准入与过滤标准：
- **监控主体清单**：标准公司名称、官方主页域名、核心产品名称、常见别名；
- **跟踪事件类别**：产品功能发布、定价调整、技术白皮书、高管人事任命、安全漏洞通告；
- **实质性影响门槛**：明确过滤掉泛化的营销公关软文、日常社交媒体闲聊，仅收录具备实际业务或技术影响的新闻。

### 第二步：建立多层级信息来源矩阵
为每个监控标的梳理可信的信息获取渠道（按优先级由高到低排序）：
1. **第一优先级（官方一手来源）**：官方新闻中心、技术博客、产品发布更新日志；
2. **第二优先级（商业与合规来源）**：产品定价页面、公开财报文件、监管合规披露；
3. **第三优先级（服务状态来源）**：服务健康状态页、安全漏洞通告；
4. **第四优先级（权威行业媒体）**：知名科技媒体与财经新闻报道；
5. **弱相关参考**：官方公开招聘岗位信息（作为判断研发方向的辅助线索）。

### 第三步：固化监控契约并调度后台定时任务
1. 将监控范围、分类规则与基准抓取时间写入本地契约文件（存放在 `$HERMES_HOME/competitor-watches/<标识>.json`）：
   ```json
   {
     "slug": "ai-model-competitors",
     "companies": ["OpenAI", "Anthropic", "Google"],
     "categories": ["产品发布", "价格调整", "技术论文"],
     "last_cutoff": "2026-10-21T00:00:00+08:00"
   }
   ```
2. **创建后台定时调度任务**：
   ```
   cronjob(action="create",
           schedule="every monday 9am",
           prompt="加载 competitor-news-monitor 技能，执行 ~/.hermes/competitor-watches/<标识>.json 的定期增量跟踪任务。",
           deliver=<用户指定的投递渠道>)
   ```

## 二、 周期增量抓取与简报生成（后台定时执行）

每次定时任务触发时，执行如下标准化处理逻辑：

1. **增量检索**：
   - 以契约中记录的上次截止时间为起点，执行增量检索；
   - 对重要官方博客与更新日志页面调用 `web_extract` 抓取最新内容；
2. **事件真实性与来源强校验**：
   - 提取的信息必须包含确切的发布日期、来源标题、规范的官方原文链接；
   - 区分一手官方公告与第三方传闻，第三方报道必须核查是否有官方源头佐证；
3. **事件去重与影响评估**：
   - 同一事件被多家媒体重复报道时，必须合并整理为单条核心事实，优先引用最初发源地链接；
   - 依据实质性影响门槛过滤掉无价值的细碎日常琐事；
4. **输出结构化情报简报**：
   - 简报包含：核心动态速览（三句话结论）、分主体动态明细表（发生时间 + 事件分类 + 核心事实 + 商业/技术影响 + 来源出处链接）；
5. **推进更新时间戳**：
   - 仅当本轮抓取成功并完成简报生成后，才将契约文件中的最后截止时间更新为当前时间戳。若某数据源发生抓取失败，记录失败异常，不跳过未抓取的时间窗口。

---

## 三、 检查核对清单

- [ ] 监控标的是否锁定了标准的企业名称、核心产品与官方域名？
- [ ] 收集的事实是否具备可靠的一手官方来源链接，避免将传闻当作事实？
- [ ] 多方报道的同一事件是否完成了去重合并？
- [ ] 简报中的日期与出处链接是否完整真实，杜绝无依据推断？
