# 彩色 ASCII 字符画与终端风格视频生成指南（ASCII Video）

## 概述

指导将现有的普通视频文件、音频音轨或图像序列，转换为具备复古极客风格的高清彩色 ASCII 字符画动画与视频。支持提取视频帧亮度与色彩信息、映射为不同密度的 ASCII 字符矩阵、结合音频节拍产生声波律动，并使用 FFmpeg 重新编译为标准的 MP4 视频或循环动图（GIF）。

## 适用场景

- “把一段宣传短片转换为黑客帝国风格的绿色下落字符流视频”
- “为一段电子音乐制作纯 ASCII 字符律动的声波频谱动效”
- “生成一段复古终端字符动画并在终端命令行中直接播放预览”
- “将包含人物或物体的图像转换为高密度的彩色字符画”

## 一、 字符转换核心物理原理

字符画视频转换由四个底层步骤构成：

1. **逐帧灰度与色彩采样**：
   - 将原视频拆解为逐帧图像，并将每一帧缩放下采样为目标字符网格尺寸（例如 120 列 $	imes$ 40 行）；
   - 提取每个网格单元的像素亮度与 RGB 真实色彩。
2. **字符密度量化映射**：
   - 根据单元格的亮度值，从暗到亮映射为具有不同视觉填充密度的字符表：
     ```
     标准密度字符阶梯（由疏到密）：" .:-=+*#%@"
     ```
3. **色彩着色与画布合成**：
   - 保持字符原始灰度密度的同时，将原画面的 RGB 颜色赋予对应字符；
   - 在黑色背景画布上按固定间距的等宽字体重新渲染绘制为高清像素帧。
4. **视频与音频重新编码**：
   - 使用 FFmpeg 将重绘完成的字符帧序列与原始音频轨道进行精确同步，并压缩输出为 H.264 编码的 MP4 文件。

## 二、 常用处理范式与命令结构

本技能配套的脚本库支持全自动化的流水线作业：

### 1. 普通视频转彩色 ASCII 字符画 MP4 视频
```bash
# 调用内置转换脚本，指定网格宽度为 120 列
python scripts/render_ascii.py "input.mp4" -o "output_ascii.mp4" --width 120 --color
```

### 2. 生成黑客帝国风格（单色终端绿色流）
```bash
python scripts/render_ascii.py "input.mp4" -o "matrix_style.mp4" --color-mode green --matrix-fall
```

### 3. 生成紧凑型循环动态图（GIF）
```bash
python scripts/render_ascii.py "input.mp4" -o "preview.gif" --format gif --fps 15
```

## 三、 输出质量与性能优化纪律

1. **字体必须选用等宽字体**：
   - 渲染字符帧时必须强制指定等宽字体（如 Courier New、Consolas、JetBrains Mono），严禁使用比例字体，否则会导致字符横向错位、网格扭曲；
2. **分辨率与字符网格平衡**：
   - 字符网格宽度建议设置在 80 到 160 列之间：过小则画面细节模糊，过大则字符尺寸缩小到难以辨认；
3. **交付呈现**：
   - 生成的视频文件存放在指定目录后，使用标准格式直接输出交付标识：
     ```
     MEDIA:<工作目录>/视频/output_ascii.mp4
     ```
