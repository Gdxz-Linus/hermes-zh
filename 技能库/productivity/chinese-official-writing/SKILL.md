# 中文公文与专业文书写作规范（Chinese Official Writing）

## 概述

规范中文党政公文、企事业单位事务性材料、技术工作汇报与项目方案的起草、审核与修改。保障公文逻辑严密、行文合规、结构庄重，严格贯彻“结论先行、据实撰写、去口语化与降 AI 味”的最高语言标准。

**核心铁律**：
1. **据实成文，严禁虚构**：公文中的时间、地点、数字、审批节点与责任主体必须以真实提供的背景材料为准，严禁凭空编造事实或假冒公章机构；
2. **严守文种边界**：一文一事，请示不抄送下级机关，报告中不得夹带请示事项；
3. **彻底去除 AI 腔调**：严禁出现空泛无据的修饰辞藻与非正式互联网流行语，整篇文档做到“第一遍读就懂”。

## 一、 常见法定文种选用与行文关系

必须根据行文目的与上下级层级关系选择正确的法定文种，严禁文种混淆：

| 文种类型 | 适用行文方向 | 核心功能与使用规约 | 核心结语规范 |
| :--- | :--- | :--- | :--- |
| **请示** | **上行文** | 向上级请求指示、批准特定事项；**严格遵循一文一事**；不得抄送下级。 | “妥否，请批示”、“当否，请批示” |
| **报告** | **上行文** | 向上级汇报工作、反映情况、回复问询；**严禁夹带请示与资金申请**。 | “特此报告”、“专此报告” |
| **通知** | **下行文 / 平行文** | 传达要求下级办理的事项、发布规章制度、任免人员、部署特定工作。 | “请认真遵照执行”、“请结合实际贯彻执行” |
| **通报** | **下行文** | 表彰先进、批评错误、传达重大情况与典型事故警示。 | “特此通报” |
| **函** | **平行文** | 不相隶属机关之间商洽工作、询问答复、请求批准或向主管部门申请。 | “特此函商”、“请予支持为盼”、“特此函复” |
| **纪要** | **综合文种** | 记载会议主要情况、讨论议定事项与各方分工责任。 | “会议决定”、“会议要求” |
| **方案 / 意见** | **下行文 / 综合** | 对重要工作作出全面部署、阐明目标、分解实施阶段与保障措施。 | 视具体方案而定 |

## 二、 语言风格与“去 AI 味”规范

撰写公文时，必须将大模型常见的空泛、修饰性语言替换为庄重、明确的书面公文用语：

### 1. 禁用词汇与规范替换表
- 禁用网络非正式词汇与空泛辞藻；
- 禁用常见转折与感叹（如“不难看出”、“显而易见”、“令人瞩目”）；
- 严格遵循统一的词到词规范替换，杜绝口语与行话。

### 2. 句式与结构原则
- **结论先行**：段落首句直接交代办成了什么、决定了什么或提出了什么要求；
- **主谓宾完整**：一个句子阐述一件确定的事，责任人与受体明确；
- **数字精确量化**：禁止使用“大幅增长”、“极快”、“相当多”等模糊形容词，必须陈述确切数字（如“同比上升 12.5%”、“完成 48 项整改”）。

## 三、 常用公文标准正文结构

### 1. 工作请示标准结构
```
关于 [申请事项名称] 的请示

[主送机关名称]：

[引言：简要陈述申请事项的起因、政策依据或当前面临的客观紧迫情况]...

[主体：分项陈述具体请示内容，包含实施方案、预算明细、论证依据及预期成效]：
一、 申请背景与必要性分析
二、 拟实施的具体工作方案
三、 经费预算与资源保障清单

[结语：使用法定谦敬结语]
妥否，请批示。

[发文机关署名]
[印发日期，如：2026年10月20日]
```

### 2. 会议纪要标准结构
```
[会议名称] 纪要

[时间、地点、主持人、出席人员、列席人员、记录人]

[引言：会议召开的背景、主要任务与议题]...

[主体：按议定事项分条列项归纳，突出决议与分工]：
一、 会议听取了...工作汇报，一致认为...
二、 会议原则同意...方案，由 [具体责任部门] 牵头落实...
三、 会议强调，各项任务必须于 [确切截止日期] 前完成...

[纪要整理送发范围]
```

### 3. 工作方案标准结构
```
[项目名称 / 专项工作] 实施方案

一、 总体目标与工作原则
二、 核心任务与具体分工（明确任务、牵头部门、配合单位）
三、 推进实施步骤（筹备阶段、实施阶段、总结验收阶段）
四、 保障措施（组织领导、经费支持、督促通报、安全合规）
```

## 四、 拟稿与审校自检清单

- [ ] 文种选择是否与发文机关和受文机关的层级关系严格对应（请示绝不抄送下级）？
- [ ] 请示是否严格做到了“一文一事”？报告中是否杜绝了夹带资金或审批请求？
- [ ] 全文数字、时间、机构名称是否完全基于真实材料，没有任何凭空编造？
- [ ] 是否彻底清除了空洞修饰词与非规范词汇？
- [ ] 结尾结语是否符合该文种的法定规范格式？
