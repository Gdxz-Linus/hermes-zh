# 社交媒体平台官方 CLI 交互指南（xurl）

## 概述

指导在终端环境中使用 X 官方开发者平台推出的命令行工具 `xurl`，对社交媒体推文、用户动态、私信与富媒体内容进行程序化管理。支持原生查询指定帖子详情、关键词搜索、时间线获取、动态发布与媒体资源上传。

**机密安全绝对铁律**：
```
严禁在会话中索要、输出或解析任何 API 密钥与访问令牌明文
```
所有关于账号的凭据注册与 OAuth2 授权，必须由用户在终端命令行中自行完成，系统绝不读取、解析或在聊天中显示 `~/.xurl` 凭据文件内容。

## 适用场景

- “查询某条社交推文的完整正文、发布时间、互动数据与作者信息”
- “根据指定关键词检索最近的热门讨论与推文列表”
- “通过命令行发布一条包含文字或媒体图片的工作动态”
- “解析某个推文链接背后的底层结构化元数据 JSON”

---

## 一、 凭据安全与账号授权准则

1. **凭据文件完全隔离**：
   - 令牌安全保存在本地用户主目录下的 `~/.xurl` 中，采用 OAuth 2.0 PKCE 流程支持自动静默刷新；
   - **禁止使用的命令行参数**：严禁在指令中内联传递机密参数（如 `--bearer-token`、`--consumer-key`、`--client-secret` 等）；
2. **凭据状态核验命令**：
   - 验证当前凭据是否有效，唯一允许调用的命令为：
     ```bash
     xurl auth status
     ```
   - 若状态正常，说明当前终端环境已就绪。

---

## 二、 常用数据检索与操作范式

所有命令默认将结构化 JSON 输出到标准输出流：

### 1. 根据唯一 ID 提取单条推文
获取指定帖子的完整字段、作者信息与互动指标：
```bash
xurl post <推文ID>
```

### 2. 关键词检索最新推文
检索包含特定主题标签或关键词的推文列表（最近 7 天内）：
```bash
xurl search "人工智能 架构" --limit 10
```

### 3. 查看指定用户的个人主页推文时间线
```bash
xurl timeline <用户名> --limit 5
```

### 4. 发布新推文（必须经用户明确确认）
经用户确认内容后发布动态：
```bash
xurl post create "系统新版本已正式上线，相关技术说明请参阅官方文档。"
```

### 5. 上传媒体图片并附带发布
```bash
xurl media upload "D:/Hermes/图片/preview.png"
# 结合上传返回的 media_id 发布推文
xurl post create "最新系统架构图发布" --media-id <返回的媒体ID>
```

## 三、 使用纪律与异常处理

1. **调用频率限制意识**：X API 对不同的数据端点设有严格的每 15 分钟请求窗口上限；在编写自动化查询脚本时，避免短时间内高频轮询；
2. **发布类操作确认机制**：所有涉及对外公开发布动态、发送私信或删除帖子的动作，必须向用户完整呈现内容草稿并取得确认后方可执行。
